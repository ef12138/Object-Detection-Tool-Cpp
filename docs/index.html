03PID 算法

PID 是 Proportional–Integral–Differential 的缩写，即比例、积分、微分控制。它根据系统误差（目标值 − 实际值）计算控制量，使系统达到稳定状态。PID 适用于温度、速度、位置、压力等各种控制场景。

04贝塞尔曲线

位移不直冲：起点是准心、终点是框心，两个控制点（虚线小圆）决定弧往哪边拐。曲线再按时间拆成几十个小步，起手快、临门减速，不会一冲过头。

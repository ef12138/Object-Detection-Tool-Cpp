纯 C++ / Qt 写的三角州行动实时目标检测自动瞄准工具

抓屏幕中心的一块画面 → 跑目标检测 → 把框画回屏幕上 → 按住某个键时，把鼠标朝目标方向推一点。

抓屏DXGI Desktop Duplication，推理ONNX Runtime（DirectML），绘制透明置顶 Qt 窗口。

性能翻倍：同一个模型、同一块显卡，从抓屏到推理到出框整条链路都在显存里走完，省掉 Python 解释器和 PyTorch 的调度与来回拷贝。

01实时检测

DXGI Desktop Duplication 直接拿 GPU 上的画面纹理，不进内存、不落盘。框跟着目标走，256 档一秒钟出 276 次结果。

02叠加层不污染抓屏

透明置顶窗口带 WDA_EXCLUDEFROMCAPTURE，系统层面就把它从抓屏里剔除。自己画的框不会被下一帧抓回来，也就不会越叠越花。

03弧线瞄准

误差先过 PID，再拆成几十个小步用 SendInput 送出去，鼠标是一条弧线滑过去，不是瞬间闪现。松开热键立刻停。

按住
松手立即停

04只在按住时动

检测一直跑，鼠标只在热键按下期间响应。键抬起的那一刻，下一个位移包就不再发出，不存在「松了还在飘」。

Pipeline

一帧要走过的五道工序

从抓屏到画出框，中间没有一次回主存拷贝。串行定时器把这条链拉成流水线，抓屏和推理互不阻塞。

STEP 1抓屏Desktop Duplication 取纹理
STEP 2letterbox等比缩放 + 114 灰边
STEP 3推理DirectML 会话，GPU 内完成
STEP 4后处理sigmoid · 阈值 · 同类 NMS
STEP 5叠加层144 Hz 独立重绘

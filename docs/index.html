01实时检测

DXGI Desktop Duplication 直接拿 GPU 上的画面纹理，不进内存、不落盘。框是四个角的短线，框上方那条血条就是置信度，256 档一秒钟出 276 次结果。

02叠加层不污染抓屏

透明置顶窗口带 WDA_EXCLUDEFROMCAPTURE，系统层面就把它从抓屏里剔除。自己画的框不会被下一帧抓回来，也就不会越叠越花。

PID · 位置环
误差曲线

03PID 位置环

框心和屏幕中心差多少，就把这个误差喂给 PID：P 拉回来、D 压过冲、I 补掉长期偏差。目标在跳、画面在抖，输出的仍然是一条平滑的位移——和无人机悬停自稳是同一套东西。

04贝塞尔曲线

位移不直冲：起点是准心、终点是框心，两个控制点（图上的小圆圈）决定弧往哪边拐。曲线再按时间拆成几十个小步，起手快、临门减速，不会一冲过头。

已锁定

05瞄准

准心沿贝塞尔滑到框心，到位才亮锁定框。整条链路由一个相对位移包驱动，热键一抬，下一个包就不再发出。

Pipeline

一帧要走过的五道工序

从抓屏到画出框，中间没有一次回主存拷贝。串行定时器把这条链拉成流水线，抓屏和推理互不阻塞。
